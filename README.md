# @magic_01/dsh-sidebar-todo

DeepSeek Harness 左侧栏的常驻待办清单。

## 功能

- 创建待办有两种方式：
  - 一句话：在输入框输入 `交周报 明天 18:00 !1 #工作 ^工作`，回车即建。
  - 表单：点标题栏「＋ 新建」（或按 `c`）打开表单，可填标题、备注、子任务、分类、优先级、截止、重复、标签。
- 左侧栏「待办」入口 + 页面：智能视图（今天 / 周视图 / 月视图 / 全部 / 已完成）、分类、标签。
- 一行输入完成捕获：`交周报 明天 18:00 !1 #工作 ^工作`。
  - `!1` / `!2` / `!3`：优先级（高/中/低）
  - `#标签`：单个标签；`^分类`：放进指定分类
  - `今天`、`明天`、`后天`、`大后天`、`今晚`、`明早`
  - `周一` … `周日`、`下周一`
  - `2026-11-30`、`11-30`、`11月30日`
  - `18:00`、`18点`、`18点半`、`下午 3:30`
  - 只写日期时按当天 23:59:59 处理；只写时间时，过了今天该时刻则排到明天。
- 任务支持“开始 → 截止”的时间段：新建表单和详情里都可设开始时间；列表/看板显示范围，重复任务推进时保留原时长。
- 点击任务打开右侧详情抽屉：标题、备注、子任务、分类、优先级、开始/截止、标签、提醒、重复规则。
- 子任务：默认在任务行下方展开显示，可直接勾选、删除、点「＋ 子任务」添加；点“子任务 n/m”收起；看板卡片同样可勾选/删除/添加，详情里可管理完整列表。
- 提醒：每个任务最多 5 个；可按“截止时 / 提前 1 小时 / 提前 1 天 / 自定义时间”添加，支持“稍后 10 分钟”，触发后标记已提醒。
- 重复任务：每天 / 工作日 / 每周（选星期几）/ 每月 / 每年；完成时自动生成下一次，并保留系列 id。
- 分类可新建、重命名、删除（删除时任务移入收件箱）；分类可移动到文件夹；文件夹可新建、重命名、删除（删除后分类回到未分组）。
- 分类支持背景色：新建时选色板或自定义颜色，之后点分类的 ✎ 改色；侧栏分类、任务行左侧色条与淡背景、看板列、日历 chip 都使用该颜色。
- 标签可重命名（重名即合并）、删除。
- 排序：智能排序 / 手动排序 / 按截止日期；手动排序下可拖拽任务调整顺序。
- 视图：列表 / 看板 / 日历 / 四象限 / 统计。
  - 看板按优先级或分类分列，拖拽卡片改优先级或分类。
  - 左侧「周视图」「月视图」直接打开对应日历；不再有顶部的月/周/日切换器和日视图。
  - 月视图按天落任务，周视图 7 列按天排。可前后翻页、回到今天；鼠标滚轮可切换上一/下一周或月。
  - 有开始和截止的任务会出现在开始日（标“开始”）和截止日（标“截止”）；无日期的任务显示在顶部「未排期」区。
  - 拖任务到某天改日期（保留原时间）。
  - 四象限按“紧急（今天或未来 2 天内到期、逾期）”和“重要（P2/P3）”自动分组。
  - 统计显示近 30 天完成柱状图、未完成/已完成/逾期/完成率，以及按分类、标签的未完成分布。
- 批量模式：多选任务后批量完成、移动到分类、删除。
- 键盘：`n` 聚焦快速添加、`c` 新建表单、`/` 聚焦搜索、`j/k` 移动选中行、`Enter` 打开、`x` 勾选、`Esc` 关闭详情/新建/退出批量。
- 勾选完成、删除后可撤销（6 秒内，软删除 + 恢复）；搜索标题/备注/标签/子任务。
- 应用打开时，插件每 30 秒扫描一次到期提醒并触发浏览器通知（页脚授权一次）；切到对话页后仍然生效。
- Agent 可通过 `todo_manage` 工具读写同一份数据，支持 repeat/subtasks 参数；完成重复任务会返回下一次。

## 数据迁移

- 0.1.0（单分类）→ 3.0：迁移为分类/任务模型，保留 `state.v1.json`。
- 0.2.0（v2）→ 3.0：给有截止时间的旧任务补一条“截止时”提醒，保留 `state.v2.json`。
- 旧优先级 高/中/低 映射为新模型的 高/中/低；已完成任务保留 90 天后清理，软删除任务保留 30 天。

## 安装

从 npm：

```sh
dsh plugin --profile <profile> add @magic_01/dsh-sidebar-todo
```

`<profile>` 换成你的 profile 名（桌面版通常是 `desktop`，网页版通常是 `web`）。也可以在插件页 **添加插件** 里搜索包名安装。

本地开发时直接装目录：

```sh
dsh plugin --profile desktop add E:\work\deepseek\dsh-sidebar-todo
```

安装后左侧栏会出现「待办」；客户端半边改动需要刷新页面或重启一次应用。

## 数据

`$DSH_HOME/dsh-sidebar-todo/state.json`（默认 `~/.dsh/dsh-sidebar-todo/state.json`），原子写。卸载插件不会删除这份数据。

## 已知限制

- 提醒只在应用打开时触发，没有后台推送。
- 重复规则按本地时区计算；自定义 RRULE、跨时区迁移未做。
- 拖拽排序只在“手动排序”下生效；窄窗口（<720px）隐藏分类栏，暂没有替代选择器。
- 没有保存筛选、增量同步、时间线/甘特视图；看板与日历只展示当前选择范围内的任务。
- 备注是纯文本 textarea，暂未渲染 Markdown。
- 不做多端同步；数据在本机。
- 界面文案目前只有中文，未接入 DSH 的 locale 字典。
- Agent 工具是 `todo_manage`，不是内置的 `todo_write`（两者互不影响）。
